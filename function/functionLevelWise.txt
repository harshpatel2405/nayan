===============================
FUNCTION PROGRAM QUESTION BANK
===============================

--------------------------------
1) WITHOUT RETURN, WITHOUT ARGUMENT
--------------------------------
1. Print your name.  
2. Print "Hello, World!" 10 times.  
3. Print first 10 natural numbers.  
4. Display multiplication table of 5.  
5. Print all even numbers between 1 and 50.  
6. Print sum of first 100 natural numbers.  
7. Print squares of numbers from 1 to 10.  
8. Check whether a number is prime (input inside function).  
9. Print Fibonacci series up to 10 terms.  
10. Print all prime numbers between 1 and 100.  

--------------------------------
2) WITHOUT RETURN, WITH ARGUMENT
--------------------------------

1. Accept a number and print its square.  
2. Accept a number and print whether it is even or odd.  
3. Accept two numbers and print their sum.  
4. Accept two numbers and print their product.  
5. Accept a number and display its multiplication table.  
6. Accept two numbers and print the greater one.  
7. Accept a string and print it in reverse.  
8. Accept marks and print grade (A, B, C, etc.).a
9. Accept an array of numbers and print all even numbers.  

--------------------------------
3) WITH RETURN, WITHOUT ARGUMENT
--------------------------------

1. Return a fixed number (like 10).  
2. Return the current year (hardcoded).  
3. Return sum of first 50 natural numbers.  
4. Return the largest of three fixed numbers.  
5. Return factorial of 5.  
6. Generate and return a random number.  
7. Return area of a circle with fixed radius.  
8. Return whether a fixed number is palindrome or not.  
9. Return sum of squares of first 10 numbers.  
10. Return whether a fixed number is Armstrong number.  

--------------------------------
4) WITH RETURN, WITH ARGUMENT
--------------------------------

1. Return square of a given number.  
2. Return cube of a given number.  
3. Return maximum of two numbers.  
4. Return minimum of two numbers.  
5. Return whether a number is prime.  
6. Return GCD of two numbers.  
7. Return LCM of two numbers.  
8. Return area of circle using radius.  
9. Return sum of digits of a number.  
10. Return length of a string.  

--------------------------------
5) COMBINED QUESTIONS
--------------------------------

1. Create a program with four functions for calculator operations (+, -, *, /).  
2. Use one function to accept marks, another to calculate percentage, another to return grade, and finally display result.  
3. Input an array, print it using one function, find sum using another, and return maximum using another.  
4. Input a string, check palindrome using another function, print result using third.  
5. Input number, check prime, return factors, and print them.  
6. Menu-driven program for area calculation: circle, rectangle, triangle (use different function types).  
7. Program with functions to take salary, calculate HRA/DA, return gross salary, and print it.  
8. Library system: one function to take book details, another to check availability, another to return fine, and final to display record.  
9. Student result system: input marks, calculate percentage, decide grade, and print result.  
10. Program with multiple functions to implement mini ATM system (withdraw, deposit, balance check).  

--------------------------------
6) RECURSION QUESTIONS
--------------------------------

1. Recursive function to print numbers from 1 to N.  
2. Recursive function to print numbers from N to 1.  
3. Recursive function to calculate sum of digits of a number.  
4. Recursive function to calculate factorial of a number.  
5. Recursive function to generate Fibonacci series.  
6. Recursive function to calculate power of a number (a^b).  
7. Recursive function to find GCD of two numbers.  
8. Recursive function to reverse a string.  
9. Recursive function to check whether a number is palindrome.  
10. Recursive function to solve Tower of Hanoi.
